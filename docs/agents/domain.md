# Domain guidance

Before exploring Waves code:

1. Read [GLOSSARY.md](../../GLOSSARY.md). Use its terms in code, tests, issues,
   and proposals. If a needed concept is missing, identify the gap rather than
   inventing a synonym.
2. Use [the documentation map](../README.md) to find the area's specification
   and ADRs. Read the relevant decisions in [docs/adr/](../adr/) before changing behavior.
3. State any conflict with an existing ADR explicitly, naming the record and
   the proposed change. Keep accepted decisions authoritative until revised.
